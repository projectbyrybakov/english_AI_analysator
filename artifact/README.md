# Версия-артефакт (временный хостинг в Claude)

Статическая страница, которая работает внутри claude.ai: данные хранит в базе артефакта, AI-анализ делает через Claude пользователя. Нужна, пока основное приложение не развёрнуто на сервере и не выбрана модель.

Ссылка: https://claude.ai/artifact/U14QWBTwJqvoGV75mbfYhR (приватная, видна только владельцу).

## Файлы

| Файл | Что делает |
| --- | --- |
| `index.html` | каркас страницы |
| `parser.js` | порт парсера `backend/app/parser` на JS; результаты совпадают с Python на 14 тестовых случаях |
| `analysis.js` | промпты, проверка ответа модели, метрики, банк ошибок, интервальное повторение |
| `app.js` | интерфейс: занятия, отчёт, банк ошибок, практика, настройки |
| `styles.css` | оформление, светлая и тёмная тема |
| `dev/` | имитация среды Claude для локальной проверки (не публикуется) |
| `tests/` | тесты `node --test artifact/tests` |

## Возможности страницы (capabilities)

- `db` + `user` — данные в `data/users/<id>/eia/...`: личный раздел, недоступный другим, даже владельцу при общем доступе.
- `sample` — вызовы Claude для анализа, сводки, упражнений и проверки ответов. Расходуют лимиты подписки пользователя.
- `downloads` — экспорт JSON, CSV банка ошибок и HTML-отчёта.

## Как устроен анализ

1. Реплики ученика разбиваются на пакеты по 4, до двух пакетов параллельно. Пакет, ответ на который не разобрался, делится пополам и повторяется один раз.
2. Каждое замечание проверяется кодом: фрагмент должен дословно встречаться в реплике. Повторы и запинки отбрасываются отдельным фильтром.
3. Сводка, интервью-анализ и предварительный CEFR — отдельный вызов по проверенным замечаниям. Уверенность CEFR ограничена 60%, беглость и произношение отбрасываются.
4. Упражнения создаются по 5 главным ключам ошибок.
5. Все числа считает `computeMetrics`, не модель. Каждый повторный анализ сохраняется новой версией.

## Локальная проверка

```bash
node --test artifact/tests
cd artifact && python3 -m http.server 8765   # открыть http://localhost:8765/dev/test.html
```

## Публикация

Публикуется через инструмент артефактов Claude: файлы `index.html`, `styles.css`, `parser.js`, `analysis.js`, `app.js`; capabilities `{db:{}, user:{}, sample:{}, downloads:true}`.

## Ограничения

- Работает только в claude.ai под вашим аккаунтом; без входа данные не сохраняются.
- Нет еженедельных тестов, Interview Lab с живым интервьюером, графиков словаря по времени и PDF (есть HTML-отчёт для печати в PDF).
- Лемматизации нет: лексика считается по словоформам.
