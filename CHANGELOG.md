# Changelog

## [0.1.0] — 2026-11-08

Этап 1, срез 1: приём и нормализация занятий.

### Добавлено

- Парсер расшифровок: обратный и прямой порядок, автоопределение по сигналам с уверенностью, роли, свёрнутые реплики, служебные надписи, заголовок сценария, метки длительности.
- API: предпросмотр, сохранение с подтверждением, список, карточка, исходный текст, удаление, настройки.
- База: users, user_profiles, sessions, session_sources (неизменяемый), session_turns, audit_events; миграция Alembic.
- Интерфейс: новое занятие с предпросмотром и правкой ролей, список, карточка с оглавлением, настройки, светлая/тёмная тема, адаптивная вёрстка.
- Тесты: парсер (16), API на PostgreSQL (12), e2e в браузере на трёх размерах экрана (4).
- Docker Compose, GitHub Actions CI, документация.
