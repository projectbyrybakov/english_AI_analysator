# Требования к нейросети (кратко)

Полная версия для специалистов — документ «ТЗ на нейросеть: English Interview Analyst» в Claude Docs. Здесь — то, что важно для кода.

## Задачи

| Задача | Когда | Модель |
| --- | --- | --- |
| A. Лингвистический разбор реплик ученика | 1 раз на занятие | сильная |
| B. Анализ ответа на интервью (без выдуманных фактов) | 1 раз на занятие | сильная |
| C. Сверка с банком ошибок | 1 раз на занятие | средняя |
| D. Генерация упражнений | ежедневно | средняя |
| E. Проверка ответов на упражнения | часто, коротко | дешёвая |
| F. Еженедельный тест | раз в неделю | сильная |

## Контракт

- Вход: реплики в хронологическом порядке (после парсера), сценарий, компактный профиль ученика, словарь сущностей.
- Выход: JSON по версионируемой JSON Schema. Каждое замечание: `turn_id`, дословный `evidence`, `category`, `status`, `priority`, исправления, объяснение, правило, гипотеза причины с confidence, общий `confidence`.
- Статусы: `confirmed_error`, `likely_issue`, `naturalness`, `style_register`, `acceptable_variant`, `recognition_uncertainty`, `not_enough_context`.

## Проверки на стороне кода

- JSON проходит схему, иначе одна повторная попытка, затем ошибка прогона.
- `evidence` дословно входит в текст реплики `turn_id`, иначе замечание отбрасывается и логируется.
- Повторы и запинки не могут быть `confirmed_error`.
- Все числа и проценты считает код.
- Текст расшифровки передаётся как данные, не как инструкции.
- Токены и стоимость логируются; лимит $1 на занятие, предварительная оценка перед запуском.
- Провайдер подключается через адаптер, ключ только на сервере.

## Выбор модели

Сравнение кандидатов на эталонном наборе (3–5 размеченных занятий): валидность JSON, точность, полнота P1/P2, ложные ошибки на дисфлюентности, выдуманные факты, стабильность, цена и время. Пороги — в полной версии.
