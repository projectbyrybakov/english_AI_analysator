# ADR 0002. Парсер без LLM

Дата: 2026-11-08. Статус: принято.

## Решение

Порядок реплик, роли и служебные надписи определяет детерминированный код, а не нейросеть.

## Почему

- Бесплатно и мгновенно, работает без ключа API.
- Результат воспроизводим и покрыт тестами (ТЗ, приёмочные тесты A–E).
- Ошибка порядка ломает весь последующий анализ, поэтому решение должно быть объяснимым: пользователь видит сигналы и уверенность.
- При неуверенности решает пользователь в предпросмотре, а не модель.

## Следствия

Новые форматы расшифровок требуют обновления `markers.py` и тестов. LLM может понадобиться только как запасной вариант для сильно нестандартных текстов — не раньше, чем такие тексты появятся.
